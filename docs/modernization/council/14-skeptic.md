# 14 — Dissent
**General SKEPTIC · Byzantine Council**

## EXECUTIVE VERDICT

**“Make Mezzanine as good as or better than WordPress” is a category error.** WordPress is a gravity well (hosting, agencies, Upwork, SEO industry, .org plugins). You cannot out-feature gravity.

Wagtail already is “serious Django CMS.” Payload/Sanity already are “modern headless.” A fork inherits brand death and a debt graph (Grappelli, TinyMCE 4, Bootstrap 3, thread-locals, Cartridge).

## What would have to be true (and is not)
Eight figures of capital. A labor market. cPanel distribution. A plugin economy people get paid for. An SEO priesthood. An editor non-devs prefer to Gutenberg+Elementor. Years. A reason to pick you over Wagtail AND WordPress AND Webflow.

## Smallest non-fantasy
- **A — Hospice/LTS:** keep existing sites on supported Django, patch security, kill dead integrations. No REST, no editor rewrite, no marketplace.
- **B — Extract:** tiny Displayable/Page library on stock Django admin.
- **C — New product** that steals two ideas, new name, no WP slide, funded like a company. Should not start by forking this CSS.

## Forbidden
“Mezzanine 7: now with REST and Tailwind, the WordPress killer.”

## Vote
| Motion | Vote |
|---|---|
| Beat WordPress | NO. Category error. |
| Fork + rebrand as WP competitor | NO. |
| REST + theme pack as strategy | NO. |
| LTS for existing sites | YES, if someone wants that job. |
| Extract Page/Displayable | MAYBE. Honest. |
| New CMS, new name, no WP slide | ONLY as a real company; Wagtail is prior art. |

Do not fork gravity. If you love the models, copy the models into something small.
