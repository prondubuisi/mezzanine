# 16 — Commerce
**General COMMERCE · Byzantine Council**

## EXECUTIVE VERDICT

**Ship the commerce affordance in year 1. Do not ship a commerce engine.**

Cartridge is dead: PyPI 1.3.4 (Sep 2022), Django ≤4.1, Stripe broken since 2020. Salvage: Category is a Page, Product is a Displayable.

Year 1: `catalog` + `checkout` protocol + Stripe Checkout. Order is a receipt. Never see a PAN.

Year 2 optional adapters: Saleor, Oscar, Shopify. Never rebuild Woo. Never vendor Oscar.

Revolutionary shape: the page you already wrote can take money. Magazines, museums, NGOs, course-makers — not Utah tax.

Hard no: PCI scope, shipping plugins, Cartridge compat layer, “WooCommerce replacement” marketing.
