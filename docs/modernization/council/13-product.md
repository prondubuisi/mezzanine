# 13 — Product / GTM
**General PRODUCT · Byzantine Council**

## EXECUTIVE VERDICT / MISSION

Give the central web team of three a publishing OS that can run a hundred honest, accessible public sites — without WordPress, without a plugin bazaar, and without begging a designer for every page.

**Rebrand to Masthead** (fallback Lectern). Do not ship “Mezzanine 6.” Editors never see Django admin.

## Year-1 ICP
Director of Web at a research university / institute. 30–300 public properties, 2–6 technical staff, 50–500 publishers. Harvest: WordPress Multisite in higher-ed.

Not: indie bloggers, Webflow designers, Woo merchants, JS headless teams, NYT-scale newsrooms.

## Three bets
1. **Federation is the primitive** — one org, many properties, central policy, local autonomy (productize Mezzanine hostname multi-tenancy).
2. **Editorial Desk is the product** — assignments, embargoes, corrections, a11y gate, grounded AI. People/Events/Stories/Pages/Forms first-class. Blog is a view.
3. **Guarded composition + Django escape hatch** — certified blocks in kits; custom typed Django types for IT; signed capability manifests; no unsigned code.

## 90 days
Desk v1 + Institute kit + draft/review/schedule + hosted preview + WP importer that preserves URLs + a11y lint. Burn Twitter/Cartridge/admin-as-product.

## 12 months
Federation, Campus SSO, WP Multisite migrator, 3 more kits, AI Desk, audit/retention/corrections, static snapshot export, 10 certified agencies.

## Never
Woo clone, infinite marketplace, Webflow competition, Django admin as product, “Mezzanine 6 now with REST.”

## Licensing
Apache/BSD core + hosted Cloud + paid Campus. Preview $0, Institute $249/mo, Federation $999/mo, Campus $12–60k/yr.
