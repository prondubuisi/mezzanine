# 10 — WordPress Competitive Map (2026)
**General WORDPRESS · Byzantine Council**

## EXECUTIVE VERDICT

WordPress is not a CMS. It is owned-web publishing with a labor market, hosted for $5–$30/month, 41.1% of all websites (W3Techs 11 Aug 2026), slowly shrinking (43.4% → 41.1% in a year). You cannot beat gravity. You can steal ONE job.

**The job:** Give a non-developer a website they own, on a URL they control, that they (or a cheap agency) can change on Tuesday without a deploy pipeline.

**The only wedge that can steal share in 24 months:** one-click WordPress migrate that preserves URLs/SEO + AI-native authoring on *typed* content.

## Must match
Non-dev publish (draft/preview/schedule). Visual pages not just posts. SEO primitives + 301 map. Media library. Author/Editor/Admin roles. Forms. 60-second first run. Obsessive WP import. Commerce *story* (not Woo clone). Command palette + async editorial. AI that fills fields. Fast by default. Secure by default.

## Must NOT copy
Plugin hell (69k plugins, 51.5% abandoned, 11,334 vulns in 2025). PHP compat theater. Gutenberg/FSE/theme.json. Classic/Gutenberg dual stack. wordpress.org political monopoly. Everything-is-a-post.

## WP 2026 facts
- 6.8 speculative loading + bcrypt; 6.9 Abilities API + Notes; 7.0 AI Client + DataViews; RTC pulled from 7.0 and still unresolved for 7.1.
- Classic Editor still 9M+ installs. 28% block themes. 47% still use page builders.
- Playground (PHP-WASM) is the most underrated WP product.
- Automattic vs WP Engine trial Sept 2027 — governance risk is now an RFP line.

## GTM
Buyer: agency owner sick of the maintenance tax. Daily user: marketing manager. Champion: Python/platform engineer with a WP box they hate. Anti-persona: $4 Woo store.

Success metric: 100 agencies × ≥10 ex-WP sites, 90 days post-migrate, organic ≥95% of baseline.

## Implication for Mezzanine
Treat Mezzanine as *reference architecture* for typed pages, not the thing you ship to steal WP share. A Django-admin modernization is a museum project, not a WordPress strategy.
